记录的键与那句话：

```
$ARGUMENTS
```

玩家在记录页上写了要改的地方。参数是这条记录的键：`<kind>:<id>`（例如 `event:9900102`、`rite:5010901`）。

按这个顺序做：

1. 用参数找文件：`config/<kind>/<id>.json`。文件不在这个 mod 里时，先确认玩家指的是不是原版那条记录（若是，按目录式条目整份复制过来再改）。
2. 按玩家原话改**这一份记录**：改文本就改文本，改数字就改数字，改结构（加/删结算分支、换引用的卡）就改数组。不要顺手改别的字段。
3. 跑 `validate_mod`，有 `FAIL` 先改到没有。
4. 重跑 `node tools/preview.mjs --mod <ModName>`，让这一页反映新内容。
5. 回话：一句话说改了哪一处，再给这一页的工作区相对路径。玩家不需要看 JSON。

玩家的话有歧义时，先问一句再改，不要猜。

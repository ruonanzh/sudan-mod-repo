# mod 说明页

属于苏丹的游戏 mod 工作区。没读过 `mod-creator` 的话，先读它。

## 这是什么

**需求讨论的载体。** 玩家对着一个页面，比对着一段 JSON 好说话：他能看见要做哪张卡、哪些字段取什么值、卡面拼出来什么效果、剧情按什么顺序走。你写页面，他给意见，你改方案。

页面是**给玩家看的**，不是给开发看的：上面只有方案本身，没有「我做了什么」的说明，也没有输入框。

## 什么时候用，什么时候不用

用它：

- 还没定要做什么：一个 mod 想法、几种可能的做法，都可以先有一页摆给玩家挑。
- 你们要先定范围或某个值，才动手写 mod。
- 玩家要改**剧情文字**：事件叙事、选项按钮、结算提示、仪式与卡面的文案。这些文字要读起来自然，只看 JSON 里的字符串判断不出来。
- 玩家问「这个 mod 改了什么」。
- 结论要摆数字或做对比。

不用它：

- 玩家只是闲聊，或者问题一句话能答完。
- 要把 mod 装进游戏验收——那是 `mod-installer` 的事，页面证明不了任何东西能被加载。

## 生成一页

```
node tools/page.mjs <kind> --mod your_mods/<ModName> --id <id> --out your_mods/<ModName>/.preview/<名字>.html
```

支持的 kind：

| kind | 是什么 |
|---|---|
| `card` | 卡（还会拼出卡面） |
| `rite` | 仪式 |
| `event` | 事件 |
| `loot` | 战利品表 |
| `quest` | 任务 |
| `over` | 结局 |
| `afterStory` | 后日谈 |
| `upgrade` | 命运商店条目 |
| `tag` | 标签 |
| `init` | 开局 |

- **提案还没写进 mod**：加 `--spec - < 提案.json`（或用 `--spec 文件`），副标题会标「提案 · 尚未写入 mod」，不产生任何 config 文件。
- **`ModName` 还没定**：先调 `create_mod_folder(name="<小写 snake_case>")` 建目录并绑定会话，再写 `info.json`。细节在 `mod-creator` 的 `## 建 mod 骨架` 与 `## info.json`。
- `.preview/` 不属于 mod：它被 git 忽略，也不要装进游戏。

## 页面上会看到什么（脚本决定，你不用排版）

1. **每个字段都是「中文标签 + 值 + 一句说明」**。说明来自 `schema/field-labels.json`，出处是游戏研究文档。
2. **嵌套内容是小表**：槽位、结算分支、`item[]`、`target[]`、段落池等各自成表，列名也是中文标签。长表只显示前 25 行，其余收在「还有 N 条」里。
3. **条件写成一句话**：`{ "counter.7000490>=": 1 }` 显示成「计数器 大于等于 7000490」，多条件用「，并且」连起来。
4. **对象点开在下一行展开**：点「3 项」，当前行下面出现整行宽的缩进小表，不挤在单元格里。
5. **游戏不认识的键单独一节**：活键没有中文标签时页面直接失败，`FAIL` 里点名是哪个键、要加到哪个文件。

版式由 `tools/page.mjs` 与 `tools/html.mjs` 决定。你只管把记录或提案写对。

## 要对比几个方案

页面只显示**一条**记录。要比方案，就各生成一个提案页，文件名区分开：

```
--out .preview/card-9000001-a.html   # 数值保守
--out .preview/card-9000001-b.html   # 数值激进
```

然后把两个路径都给玩家，让他自己看差别。

## 玩家回话之后

1. 按玩家说的改**记录**（或 `--spec` 里的提案）。
2. 用同一个 `--out` 重新生成页面，页面就更新了。
3. 把新页面的路径再给玩家一次，说明这次改了哪几处。

玩家说「不对」而你认为原值有理由时，不要用文字反复解释：**各生成一页**，让他直接比较两页的差别。

## 不要做的事

- **不要手写 HTML 或 CSS**。页面上出现什么由脚本决定；要改版式就改 `tools/page.mjs`，要改配色字号就改 `tools/html.mjs`。
- **不要改生成出来的页面**。每次运行都按当前记录整份重渲染，同一个 `--out` 会被整份覆盖。
- **不要把页面当验收**。页面只说明方案长什么样；能不能加载、装进游戏对不对，要用 `mod-installer` 在游戏里看。

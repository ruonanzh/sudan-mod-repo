# 换游戏里的音频

**目标**：用玩家自己的音频文件，替换掉游戏里已经有的一段音频。**不支持新增**：只能换，不能加。

属于苏丹的游戏 mod 工作区。安装与启用见 `mod-installer`。

## 1. 能做什么，不能做什么

| 能做 | 做不到 |
|---|---|
| 把游戏里已经在放的一段音乐换成玩家的文件 | 给游戏新增一段音乐或音效 |
| 换 `start_game`、结局音乐等有名字的片段 | 给某个界面配一段游戏本来没有的曲子 |

**为什么只能替换**：替换走 `SFxManager.ModifyAudio`。它在场景里找一个已经挂在 `AudioSource` 上的 `ModAudioModifyer` 组件，读这个组件的 `audioName`，然后向 mod 数据要同名片段。mod 没有办法添加这个组件，所以游戏里必须先有一个正在放音乐的地方，你才能替换它。

玩家要「加一首新的」时，直接说明做不到，并把可替换的片段名一起找出来（见第 4 节）。

## 2. 放文件

```
your_mods/<ModName>/bgm/<片段名>.<扩展名>
```

- **文件名本身就是片段名。** 文件名是 `start_game.wav`，替换的就是 `start_game`。不要加前缀、不要带目录。
- 可用扩展名：`.wav`、`.mp3`、`.ogg`。
- 目前唯一的已发布例子把 `start_game` 换成 **16 位 PCM、48 kHz 的立体声 WAV**。
- `ogg` 体积小很多，而且同样被接受。文件大时优先转成 `ogg`。
- 目录会被递归扫描，所以子目录不影响识别；建议还是全部平铺在 `bgm/` 下，方便自己和玩家核对。

## 3. 装进去，看日志

装法与别的 mod 一样：复制到 mod 根目录、在游戏内面板启用（见 `mod-installer`）。然后读这个 mod 自己的日志：

```
~/DoubleCross/SultansGame/ModLog/<mod name>_local.log
```

两行日志决定成败：

| 行 | 含义 | 怎么办 |
|---|---|---|
| `mod modify key {0} {1} not found` | 文件名对不上游戏里任何音频名，什么都不播 | 换候选名再试；名字错了不会报错，只是没声音 |
| `modAudioModifyerMap already contains ` | 两个 mod 抢同一个片段，只有一个生效 | 让玩家只留一个提供该片段的 mod |

## 4. 片段名从哪来

**除 `start_game` 以外的片段名基本未知。** 已知的线索只有一条：

- `config/over_music_config.json` 列的是**结局音乐**（`over_game_dead`、`over_game_happiness` 等），但那是另一套子系统，走的是 `config/` 里的字段而不是 `bgm/` 目录。

所以做法是：

1. 先问玩家要换的是**哪个场景**的音乐：开场、结局、某个界面。
2. 到游戏自己的文件里找候选名（`config/` 下的 json 里出现的音频名）。
3. 用候选名放一份文件，进游戏听；日志里出现 `mod modify key ... not found` 就说明名字不对，换下一个。

不要凭感觉编名字。编出来的名字只会得到一行 `not found` 和一片安静。

## 5. 验收

1. `node tools/lint.mjs your_mods/<ModName>` 退出码为 0。
2. 日志里有 `read mod <name> file: bgm/<片段名>.<扩展名>`。
3. 日志里**没有** `mod modify key ... not found`。
4. 游戏里真的听到换掉的那一段。音频听不听得出来，只有玩家的耳朵能确认——把日志结果说清楚，再问玩家听到了什么。

## 6. 不要做的事

- 不要把文件放到 `bgm/` 以外。
- 不要为了「换掉」而改原版文件的名字：游戏按名字取值，名字对不上就没有声音。
- 不要承诺新增音频。做不到就说做不到。

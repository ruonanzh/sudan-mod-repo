# How the game translates text

Measured with `node tools/i18n-probe.mjs` against the shipped build, not from documentation.
This file exists because an earlier assumption — "every record has a `_name` key" — was wrong in
a way that put an option button's paragraph where an event's title belongs.

## The key grammar

`i18n/<lang>/config.json` is one flat object. Every key carries an id in the middle:

```
<KIND>_<id>_<field>            card_2000001_name
<KIND>_<id>_<field>_<n>_<...>  OPTION_5300176_option_1_ITEM_2_TEXT
```

`<KIND>` is one of: `card`, `rite`, `quest`, `over`, `after_story`, `upgrade`, `tag_lock`,
`init`, `change_card_name`, `change_card_text`, `gallery_cg`, `GALLERY_ACHIEVEMENT`, and for
event narration `OPTION`, `PROMPT`, `POP`, `CONFIRM`, `WIZARD_OPTION`, `WIZARD_SUDAN_OPTION`.

Fields for records: `name`, `title`, `text`, `subname`, and per-slot keys such as
`cards_slot_s1_text`, `settlement_0_text`, `prior_settlement_1_title`,
`random_text_r1_text`, `open_conditions_tips_0`, `target_1`, `favour_text`, `extra_<n>_title`.

| kind | records | with keys | note |
|---|---|---|---|
| card | 1294 | 1294 | `name` + `title` + `text` |
| rite | 1498 | 1498 | many per-slot keys |
| quest | 161 | 161 | |
| over | 159 | 159 | |
| after_story | 66 | 66 | |
| **event** | **1867** | **0 titles** | see below |
| event narration | 1867 | 279 option / 793 prompt | the player-facing paragraphs |

## Events are the exception

An event record has a `text` field, but it is a **short label**, not narration: median 7
characters, 84.5% are 12 characters or fewer. There is **no `event_` prefix in the translation
tables at all**, so an event title has no translation in any language.

What is translated is the narration, line by line, keyed by the same event id:

```
OPTION_<eventId>_option_<n>_TEXT            the paragraph the event opens with
OPTION_<eventId>_option_<n>_ITEM_<m>_TEXT   a button label inside that paragraph
PROMPT_<eventId>_prompt_<n>_TEXT            the paragraph shown after the choice
```

Two consequences:

1. A tool that labels an event by "the first key carrying this id" will show an option button's
   text as the event's title. Only an exact `<kind>:<id>` hit counts.
2. Narration must be fetched separately from the label. In the story graph it is attached as
   `node.nr`, and the page shows it under 叙事.

## Language fallback

`zh` is the source: it comes from the config JSON, not from a table. `en`, `ja`, `zhTW` come from
the tables and may be missing; a missing one falls back to the Chinese text and is marked
`无 en` / `无 ja` / `无 zhTW` rather than presented as a translation.
